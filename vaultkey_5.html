      How to get a Client ID (one-time setup, ~5 minutes)
      

        1. Go to console.cloud.google.com → create a project (free).

        2. APIs & Services → Library → enable Google Drive API.

        3. OAuth consent screen → External → add your Gmail as a test user.

        4. Credentials → Create Credentials → OAuth Client ID → Web application.

        5. Under Authorized JavaScript origins, add the URL where you open this app (e.g. http://localhost:8000 or your hosted link).

        6. Paste the Client ID above. Note: Google sign-in doesn’t work from a file:// page — host the file first (Netlify Drop is free).
